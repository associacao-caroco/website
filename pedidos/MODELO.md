# Modelo de pedido de alteração / Change request template

Copie o texto abaixo para o seu ficheiro novo em `pedidos/` e preencha. Apague as linhas
que não se aplicam. Ver [CONTRIBUTING.md](../CONTRIBUTING.md) para os passos.

Copy the text below into your new file in `pedidos/` and fill it in. Delete the lines that
do not apply. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the steps.

```markdown
## Página / Page

Qual página, ou "nova página".
Which page, or "new page".

## O que mudar / What to change

Descreva a alteração. Se for para substituir texto, diga qual é o texto atual.
Describe the change. If text is being replaced, say which text is there now.

## Texto novo / New text

Cole aqui o texto novo, se já o tiver. Português, inglês, ou ambos.
Paste the new text here if you have it. Portuguese, English, or both.

## Imagens / Images

Nomes dos ficheiros enviados por email para info@caroco.pt, se houver.
Names of files emailed to info@caroco.pt, if any.

## Prazo / Deadline

Se houver uma data a cumprir.
If there is a date to meet.
```

## Notas

- O site é bilingue. Se enviar texto só numa língua, a outra versão é escrita depois e
  fica visível no pull request para revisão.
- Não se usam travessões (em-dash ou en-dash) em nenhum texto do site. Vírgulas, dois
  pontos, parênteses ou pontos médios.
- O rodapé legal (nome, NIPC, CAE, sede, email) aparece em todas as páginas e não se
  remove.

## Notes

- The site is bilingual. If you send text in one language only, the other version is
  written afterwards and shown on the pull request for review.
- Em-dashes and en-dashes are not used anywhere in the site text. Use commas, colons,
  parentheses, or middle dots.
- The legal footer (name, NIPC, CAE, registered office, email) appears on every page and
  is not removed.
